# Robot Viewer 工程说明文档

## 1. 项目概述

**Robot Viewer** (v1.2.2) 是一个基于 Web 的机器人模型 3D 查看器，运行于浏览器端，无需安装任何软件。用户可拖放机器人模型文件到页面，即可实现模型的可视化、关节交互、测量和物理仿真。

- **在线演示**：http://viewer.robotsfan.com/
- **许可证**：Apache-2.0
- **开发者**：范子琦 (Ziqi Fan)

## 3. 功能概览

### 3.1 支持的文件格式

| 格式 | 说明 | 加载方式 |
|------|------|---------|
| URDF | 统一机器人描述格式 | urdf-loader 解析 + URDFAdapter 转换为统一模型 |
| Xacro | ROS 宏格式 | xacro-parser 宏展开后走 URDF 流程 |
| MJCF | MuJoCo XML 格式 | MJCFAdapter 自行解析 XML 并创建 Three.js 场景 |
| USD | 通用场景描述（部分支持） | 通过内嵌 iframe 加载 WASM 版 USD Viewer |

### 3.2 核心功能

- **模型可视化**：视觉模型、碰撞几何体、惯性张量、质心 (COM)、坐标系帧、关节旋转轴
- **交互式关节控制**：通过滑块数值调节或直接拖拽模型上的关节，实时改变机器人姿态
- **测量工具**：Ctrl+点击选择两个物体，显示两点间的空间距离及其 X/Y/Z 轴投影，支持地面高度测量
- **代码编辑器**：内嵌 CodeMirror 编辑器，修改模型 XML 后点击"重新加载"即可实时预览
- **MuJoCo 物理仿真**：MJCF 模型可启动动力学仿真，支持拖拽施加力和重置
- **场景管理**：左侧文件树和模型结构图，支持文件夹批量加载、多文件切换
- **坐标系切换**：支持 +Z/-Z/+Y/-Y/+X/-X 等 6 种坐标轴朝向
- **中英文双语**：根据浏览器语言自动切换，也可手动切换
- **深色/浅色主题**：自动跟随系统，也可手动切换

## 5. 架构设计

### 5.1 整体分层

```
┌─────────────────────────────────────┐
│           UI Layer (ui/)            │  ← UIController, PanelManager, JointControlsUI
├─────────────────────────────────────┤
│        Controllers (controllers/)   │  ← FileHandler, CodeEditorManager, MeasurementController
├─────────────────────────────────────┤
│         Views (views/)              │  ← FileTreeView (DOM), ModelGraphView (D3 SVG)
├─────────────────────────────────────┤
│    Renderers (renderer/)            │  ← SceneManager (核心), + 9 个专项 Manager
├─────────────────────────────────────┤
│    Adapters (adapters/)             │  ← URDF/MJCF/Xacro/USD -> UnifiedRobotModel
├─────────────────────────────────────┤
│    Loaders (loaders/)               │  ← ModelLoaderFactory, FileLoader
├─────────────────────────────────────┤
│    Models (models/)                 │  ← UnifiedRobotModel, Link, Joint, Constraint...
├─────────────────────────────────────┤
│         Utils (utils/)              │  ← i18n, MathUtils, MeshLoader, DragControls...
└─────────────────────────────────────┘
```

### 5.2 核心数据流

```
用户拖放文件
    │
    ▼
FileHandler.setupFileDrop()
    │  检测文件类型 (URDF/Xacro/MJCF/USD/Mesh)
    ▼
ModelLoaderFactory.loadModel()
    │  根据类型路由到对应 Adapter
    ├── URDF  → urdf-loader → URDFAdapter.convert()
    ├── Xacro → xacro-parser → URDFAdapter.convert()
    ├── MJCF  → MJCFAdapter.parse()
    └── USD   → USDAdapter.parse() → iframe WASM
    │
    ▼  (转换为 UnifiedRobotModel)
    │
App.handleModelLoaded(model, file)
    │
    ├── SceneManager.addModel()     → 添加到 Three.js 场景
    ├── JointControlsUI.setupJointControls() → 生成关节滑块
    ├── ModelGraphView.drawModelGraph()  → 绘制 D3 结构图
    ├── FileTreeView.updateFileTree()    → 刷新文件树
    └── CodeEditorManager.loadFile()     → 加载到代码编辑器
```

### 5.3 统一数据模型 (UnifiedRobotModel)

所有格式（URDF、MJCF、USD）在加载后都会转换为统一的 `UnifiedRobotModel` 实例，包含：

- `links: Map<string, Link>` — 连杆映射（visuals, collisions, inertial, threeObject）
- `joints: Map<string, Joint>` — 关节映射（parent, child, axis, limits, currentValue, threeObject）
- `constraints: Map<string, Constraint>` — 约束映射（闭链/并联机构）
- `materials: Map<string, Material>` — 材质映射
- `rootLink: string` — 根连杆名称
- `threeObject: THREE.Group` — 对应的 Three.js 对象根节点

### 5.4 渲染器分层 (renderer/)

`SceneManager` 是整个渲染层的核心协调器，管理：

- **相机和渲染环**：按需渲染（dirty 标记），避免空转；动画循环通过 requestAnimationFrame 驱动
- **场景组织结构**：`scene → world (坐标系统转换) → model.threeObject`
- **坐标系统转换**：通过 `world` 节点的 rotation 实现 +Z/-Z/+Y 等 6 种朝向的动态切换

其余 9 个专项 Manager 各司其职：

| Manager | 职责 |
|---------|------|
| EnvironmentManager | 灯光（方向光 + 环境光 + 补光）、地面平面、环境贴图 |
| VisualizationManager | 视觉/碰撞几何体显示切换，模型透明度控制 |
| InertialVisualization | 惯性张量椭球体可视化 |
| ConstraintManager | 闭链约束的可视化连线与约束应用 |
| CoordinateAxesManager | 每个连杆的原点坐标系箭头，旋转关节的旋转轴箭头 |
| HighlightManager | 鼠标悬停时高亮连杆 |
| MeasurementManager | 3D 空间测量线和距离标注 |
| MujocoSimulationManager | MuJoCo WASM 物理引擎集成与仿真循环 |
| USDViewerManager | USD 模型的懒加载与 iframe 生命周期管理 |

### 5.5 适配器模式

每个适配器负责将特定格式的文件转换为 `UnifiedRobotModel`：

| 适配器 | 输入 | 转换方式 |
|--------|------|---------|
| URDFAdapter | urdf-loader 的 THREE.Group | 遍历 robot.links/joints，提取属性，补充 XML 中的惯性数据 |
| XacroAdapter | Xacro XML 文本 | 调用 xacro-parser 宏展开，生成 URDF XML，再走 URDFAdapter |
| MJCFAdapter | MJCF XML 文本 | 核心链路：parseAssets（mesh 定义）→ parseBodies（递归解析 body 树）→ parseJoints → createThreeObject（异步加载 mesh 文件并拼接层次结构） |
| USDAdapter | USD 文件 | 委托给 USDViewerManager，通过内嵌 iframe 加载 WASM |

### 5.6 关节交互机制

关节控制有两套并行的交互通道：

1. **UI 滑块**：`JointControlsUI` 为每个可动关节生成 range input 和数值输入框，用户调节滑块时直接调用 `ModelLoaderFactory.setJointAngle()`
2. **3D 拖拽**：`JointDragControls` 为每个旋转关节绑定指针拖拽平面，拖拽时实时计算旋转角并更新模型，松开时恢复 OrbitControls

两套通道都会同步更新对方的状态（滑块值、输入框值），并触发约束求解和测量更新。

### 5.7 MuJoCo 物理仿真

`MujocoSimulationManager` 的工作流程：

1. 用户点击"仿真"按钮 → `handleMujocoToggleSimulate()`
2. 首次加载时，调用 `loadScene()`：
   - 初始化 MuJoCo WASM
   - 将 MJCF XML 写入虚拟文件系统 (Emscripten MEMFS)
   - 将依赖文件（mesh、纹理）也写入 VFS
   - 调用 MuJoCo `load_from_xml` 加载模型
3. 创建仿真可视化场景 `createThreeScene()`：
   - 从 MuJoCo 引擎读取几何体数据，创建对应的 Three.js Mesh
   - 建立 `MuJoCo body → Three.js Group` 的映射
   - 从原始模型的视觉几何体中提取材质信息，应用到仿真模型上
4. 进入仿真循环：每帧调用 `simulation.step()`，将 MuJoCo 计算结果（xpos/xquat）同步更新到 Three.js 对象
5. 暂停仿真时，隐藏仿真模型，恢复原始可编辑模型

## 6. 快速开始

```bash
# 克隆仓库
git clone https://github.com/fan-ziqi/robot_viewer.git
cd robot_viewer

# 安装依赖（使用 pnpm 推荐）
pnpm install

# 启动开发服务器
pnpm run dev        # 默认 http://localhost:3000

# 构建生产版本
pnpm run build      # 输出到 dist/
```

### 构建配置说明

- 基础路径：`./`（相对路径，支持 `file://` 协议和任意部署路径）
- 压缩：Terser，生产环境自动去除 `console` 和 `debugger`
- 分包：Three.js / CodeMirror / D3 三大库各自独立分包，减少单个 chunk 体积
- 开发服务器：端口 3000，自动打开浏览器，HMR 不显示覆盖层

## 7. 核心类与接口

### 7.1 App 类 (main.js)

应用主控制器，持有所有子系统的引用并协调它们之间的交互：

- `sceneManager` — 场景管理
- `fileHandler` — 文件处理
- `jointControlsUI` — 关节控制 UI
- `panelManager` — 面板管理
- `modelGraphView` / `fileTreeView` — 视图组件
- `codeEditorManager` — 代码编辑器
- `measurementController` — 测量控制
- `usdViewerManager` — USD 查看器（懒加载）
- `mujocoSimulationManager` — MuJoCo 物理仿真

生命周期：`new App() → app.init() → animate()`

### 7.2 UnifiedRobotModel 数据类

- `Link` — 连杆（name, visuals[], collisions[], inertial, threeObject, userData）
- `Joint` — 关节（name, type, parent, child, origin, axis, limits, currentValue, threeObject）
- `VisualGeometry` / `CollisionGeometry` — 视觉/碰撞几何体（origin, geometry, material, threeObject）
- `GeometryType` — 几何体类型（type: box/sphere/cylinder/capsule/mesh, size, filename）
- `InertialProperties` — 惯性性质（mass, origin, ixx/iyy/izz/ixy/ixz/iyz）
- `Constraint` — 约束（type: connect/weld/joint/distance, body1, body2, anchor）

### 7.3 SceneManager 事件系统

`SceneManager` 提供了一个自定义事件系统 (`on/off/emit`)，关键事件：

- `modelReady` — 模型（含异步 mesh）完全加载完毕，快照移除

## 8. UI 设计说明

UI 采用 Apple Glass Design System 风格：

- 所有浮层面板使用毛玻璃效果（`backdrop-filter: blur()`）
- 顶部控制栏为居中胶囊型布局，分段组织功能按钮
- 底部常驻操作提示栏（左键旋转 / 右键平移 / 滚轮缩放 / 点击控制关节 / 拖放加载）
- 深色/浅色两套主题，通过 CSS 变量 (`--glass-bg`, `--text-primary` 等) 切换
- 面板支持折叠/关闭/最大化，动画曲线使用 `cubic-bezier(0.4, 0, 0.2, 1)` 弹性曲线

## 9. 开发指南

### 9.1 新增文件格式支持

1. 在 `src/adapters/` 创建新的 `XxxAdapter.js`，实现静态方法：`convert()` 或 `parse()`
2. 在 `ModelLoaderFactory.loadModel()` 添加新的 case 分支
3. 在 `ModelLoaderFactory.detectFileType()` 添加文件扩展名检测

### 9.2 新增可视化功能

1. 在 `src/renderer/` 创建新的 Manager 类
2. 在 `SceneManager` 构造函数中初始化
3. 在 `SceneManager.addModel()` 中调用该 Manager 的相应方法
4. 如需要 UI 控制，在 `index.html` 添加按钮，在 `UIController` 绑定事件

### 9.3 性能注意事项

- 场景使用按需渲染（dirty 标记），非活动状态不重复渲染
- 大量 mesh 文件的模型应关注异步加载时机，避免阻塞主线程
- 测量功能中的射线检测（raycaster）应仅在需要时触发
