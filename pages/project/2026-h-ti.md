## 项目概览

`2026-H-TI` 整理了 2026 年全国大学生电子设计竞赛 H 题“车载平衡滚球运动控制系统”的完赛代码和文档。系统需要在车载横梁或 PPR 管上检测并控制 1 cm 钢珠的位置，同时完成车辆行驶、循迹、停车和位置保持任务。

仓库同时包含 MaixCAM 视觉测量、图传录制、MSPM0G3507 小车主控、独立计时器板、钢珠调参控制台、运动轨迹控制台和设计报告。

## 总体架构

```text
MaixCAM 视觉工程
  640x360 图像采集 / 钢珠位置与速度检测 / UART 输出
        |
        v
MSPM0G3507 主控
  灰度循迹 / 轮速 / IMU / 航向 / 任务状态机
  钢珠位置闭环 / 总线舵机 / 蓝牙遥测
        |
        +--> PA15 --> 独立计时器 M0 板 --> OLED
        |
        +--> HC-05 --> 钢珠调参 Web 控制台
        |
        +--> 运动遥测 --> 小车轨迹 Web 控制台

MaixCAM --> WebRTC --> 浏览器图传与录制
```

## 顶层目录

| 路径 | 作用 |
| --- | --- |
| `Maixcam/` | 钢珠检测、标定、YOLO 辅助、UART 输出和 WebRTC 图传 |
| `mspm0g3507_26ti/` | 小车运动、循迹、IMU、钢珠闭环、任务状态机和遥测 |
| `TIME-OLED/` | 通过 PA15 电平控制的独立 OLED 计时器 |
| `tuchuan/` | MaixCAM 图传专用版本 |
| `tiaocan/` | 钢珠和舵机调参 Web 控制台 |
| `web/` | 小车运动轨迹 Web 控制台 |
| `latex/` | 设计报告源文件和 PDF |
| `PINOUT.md` | 硬件引脚和接线说明 |

## 硬件分工

- **MaixCAM**：固定在车体上方，识别管道中的钢珠位置和速度，并可提供 WebRTC 图传。
- **MSPM0G3507**：负责传感器采集、车辆运动、任务调度、钢珠闭环和执行器输出。
- **灰度传感器与编码器电机**：完成赛道循迹、停车线检测、速度和里程控制。
- **IMU**：提供航向角和角速度信息。
- **总线舵机**：调整横梁/管道角度，使钢珠移动或保持目标位置。
- **TIME-OLED 板**：接收主控 PA15 高低电平并显示比赛计时。
- **HC-05**：把 MCU 遥测发送到 PC 调参台。

## 通信链路

| 链路 | 用途 | 协议 |
| --- | --- | --- |
| MaixCAM UART -> MSPM0 UART1 | 钢珠位置、速度、置信度 | 115200 8N1，20 字节二进制帧，CRC16 |
| MSPM0 UART3 -> 总线舵机 | 舵机角度和速度命令 | 见 `driver/ftServo.c` |
| MSPM0 PA15 -> TIME-OLED PA15 | 计时启停 | 高电平计时、低电平暂停/停止，需共地 |
| MSPM0 UART2 -> HC-05 -> PC | 调参遥测 | 9600 8N1，20 Hz 二进制遥测 |
| 运动遥测 -> PC | 轨迹记录 | 9600 8N1，`AA 55` 帧 |
| MaixCAM WebRTC -> PC | 视频预览和录制 | HTTP/WebRTC，默认端口 8000 |

## 运行入口

### MaixCAM 视觉测量

使用 MaixVision 打开 `Maixcam/maixcam`，运行 `maixcam/main.py`。应先检查相机、UART、WebRTC、YOLO 和标定配置，并确认 `position_calibration.json` 是当前实车标定结果。比赛时 `ENABLE_SERVO_CONTROL` 应保持为 `False`，由 MCU 控制舵机。

### MSPM0G3507 主控

Keil 工程：

```text
mspm0g3507_26ti/keil/ncontroller.uvprojx
```

CCS / TI ARM Clang 工程：

```text
mspm0g3507_26ti/ticlang/ncontroller.projectspec
```

### Web 调参和轨迹记录

```powershell
cd tiaocan
npm install
npm run dev -- --host 127.0.0.1 --port 4317
```

在 Chrome 或 Edge 中打开本地地址，通过 Web Serial 连接 HC-05。`web/` 是另一套独立前端，用于记录方向、轮速、偏航角、工作模式和积分路径。

### 图传录制

```powershell
cd tuchuan\main\host
.\start_webrtc_recorder.cmd
```

打开 `http://127.0.0.1:18765`，填入 MaixCAM IP 后进行视频录制。

## 标定与调试顺序

1. 根据 `PINOUT.md`、系统配置和实际硬件完成接线核对。
2. 单独验证电机、编码器、IMU、灰度传感器和停车线判断。
3. 固定 MaixCAM、管道和补光，完成钢珠位置标定。
4. 检查 UART 帧 CRC、序号、坐标方向和超时回中。
5. 测量舵机中位、机械极限、方向和横梁角度比例。
6. 静态调试钢珠位置闭环，再进行低速车辆联调。
7. 按任务 2-7 逐项验收，并用调参台保存有效遥测记录。
